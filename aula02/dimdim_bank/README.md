# Aula 02: Comandos do Linux para Administração de Sistemas 🐧

Nesta aula através da atividade aprendemos os comandos básicos do Linux para Administração de Sistemas.

## Comandos utilizados 💻

- **mkdir**: Cria uma nova pasta (diretório)
- **cd**: Troca de pasta
- **ls -l**: Lista o conteúdo com os seus respectivos detalhes
- **touch**: Cria um arquivo vazio
- **echo**: Adicionar um conteúdo ao arquivo
- **`>`**: Cria um novo arquivo e sobrepõe o conteúdo caso já exista um
- **`>>`**: Adiciona o conteúdo no final do arquivo sem apagar o resto
- **cat**: Exibe o conteúdo do arquivo inteiro
- **cp**: Copia os arquivos do diretório
- **find**: Localiza arquivos específicos no sistema
- **grep**: Buscar informações específicas dentro dos arquivos
- **df**: Monitora o espaço disponível no sistema
- **ps**: Verifica quais processos estão rodando no sistema
- **top**: Monitora o desempenho do sistema
- **cd ~/**: Volta direto para a pasta principal do usuário
- **ls -la ***: Lista todos os arquivos e diretórios com detalhes
